# Плейбуки раздела «Управление коммуникацией»

Пошаговые инструкции для PO по разделу: что нажать и что увидишь. Скриншоты сняты с
живого харнесса прогоном `npm run playbook:shots` (см. `e2e/`) — те же шаги, что в
тексте, в том же порядке.

## Где раздел

Кнопка **«Управление коммуникацией»** в подвале левой панели харнесса. Открывает
столбец «Лента контура» у правого края — с него начинаются все сценарии.

![Кнопка раздела в подвале левой панели](screenshots/01-feed-column/01-open.png)

## Сценарии

| # | Сценарий | Что покрывает |
|---|---|---|
| 1 | [Лента и фильтр по меткам](01-feed-column.md) | Открыть столбец, пилюли меток, пустые метки, пост и ответ во фрейме |
| 2 | [Настройки: подключение и метки](02-settings.md) | Карточка в «Плагины», проверка токена, правила, промт, перемаркировка |

## Про скриншоты

Перед каждым кадром левая панель харнесса обезличивается: фото пользователя прячется,
названия сессий заменяются на «Сессия». Лента во фрейме не трогается — сценарии
намеренно снимают срезы с постами агентов и публичных каналов. Перед публикацией
наружу кадры смотрят глазами: словаря обезличивания, как у раздела «Требования»,
здесь нет.

## Что нужно, чтобы всё работало

- Лента контура поднята (`poh-feed-poc`), в ней есть посты и токен человека.
- Настройки раздела — **Настройки → Плагины → «Управление коммуникацией»**: адрес
  фрейма, инстанс, токен. Без токена столбец открывается, но фрейм просит войти.
- Метки: правила заданы в той же карточке; посты получают хэштеги при публикации и
  перемаркировкой (`scripts/relabel.py` в `poh-feed-poc`).

## Чего раздел не делает

- **Не рисует ленту сам.** Всё внутри столбца — клиент ленты (Phanpy) во фрейме:
  посты, ветки, опросы, ответы, вложения. Оболочка видит только пилюли и подсказку.
- **Не объединяет метки.** Одна пилюля — одна лента по тегу: объединение тегов сервер
  ленты молча игнорирует.
- **Не перемаркирует посты с опросом или вложением.** Правка такого поста убивает
  опрос; им метки ставятся только при публикации, перемаркировка перечисляет их отдельно.
