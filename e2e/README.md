# E2E-прогоны раздела

Playwright против **живого** харнесса с установленным плагином (см.
`docs/guides/dsh-plugin-setup.md`) в системном Chrome. Каждый файл — один сценарий из
`docs/guides/plugin-playbooks/`, шаги в том же порядке, что в тексте.

```sh
npm run test:e2e          # проверки поведения
npm run playbook:shots    # то же + кадры в docs/guides/plugin-playbooks/screenshots/
```

Адрес харнесса — `DSH_E2E_URL`, без неё `http://127.0.0.1:3082`. Харнесс не отвечает —
прогоны пропускаются, а не падают.

## Что прогоны трогают у живого харнесса

- **Ничего в документе настроек.** Сценарий 2 только читает карточку, жмёт «Проверить» и
  «Что изменится» (перемаркировка в режиме показа — ленту не правит).
- **Ничего в ленте.** Фрейм читается; ответы и голоса не отправляются.
- **Профиль браузера пустой** на каждый прогон — поэтому каждый прогон заодно проверяет
  автовход через `seed.html`.

## Кадры

Перед кадром левая панель обезличивается (`support/harness.ts`, `redact`): фото
пользователя прячется, названия сессий → «Сессия». Ленту во фрейме прогон не трогает.
